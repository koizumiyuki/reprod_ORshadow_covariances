# Orbital-shadow covariance coefficients

Code for exact symbolic evaluation of low-order RDM covariance coefficients for
orbital-rotation classical shadows. It follows the estimator and Grassmannian
moment framework in [Koizumi *et al.*, arXiv:2606.30601v1](https://arxiv.org/abs/2606.30601v1).
The published paper gives the exact 1-RDM variance formula (Eq. 6); the 2-RDM
and mixed 1-/2-RDM coefficient tables generated here are additional calculations.
This repository does not reproduce the paper's numerical figures or
sample-complexity proofs.

## Contents

```text
fs_covariance.py                    symbolic calculation and consistency checks
requirements.txt                    pinned Python dependency
LICENSE                             MIT license
outputs/reference_coefficients.tex  three selected coefficient examples
outputs/all_coefficients.tex        all 64 listed representatives
outputs/all_coefficients.pdf        rendered coefficient tables
outputs/check_report.txt           results of the built-in checks
```

The TeX tables and check report are generated by the Python command below.
The PDF is rendered from `outputs/all_coefficients.tex`. These outputs are
included so that the results can be inspected without running SymPy.

## Quick start

Python 3.11 is recommended (tested with Python 3.11.7 and SymPy 1.12).
From the repository root:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python fs_covariance.py --check reference
```

The last command is a quick smoke test; it prints `overall: PASS` when the three
reference examples agree with their expected formulas.

## Basic usage

After installation, run this command to regenerate the coefficient tables and
check report:

```bash
python fs_covariance.py --write-tex --checks --progress
```

The results are written to `outputs/reference_coefficients.tex`,
`outputs/all_coefficients.tex`, and `outputs/check_report.txt`. The full run took
about five minutes on the machine used for validation. The command exits with
a nonzero status if any check fails.

To view the three reference examples without writing files, or to run just one
named check:

```bash
python fs_covariance.py --reference
python fs_covariance.py --check k1
```

Use `--outdir PATH` with `--write-tex` to write results to another directory.
To regenerate the PDF as well, install a LaTeX distribution with `latexmk` and
run:

```bash
latexmk -pdf -outdir=outputs outputs/all_coefficients.tex
```

## Valid values of N and eta

For the complete coefficient table, a sufficient error-free range is **integer
`N >= 8` and `4 <= eta <= N - 4`** (at least four occupied and four unoccupied
modes). The representatives use orbital indices up to 8, and the most demanding
sector requires four particles and four holes. Grassmannian moments in this
calculation have degree at most 8, so their `N + content` denominators are also
nonzero in this range. The smallest example is `N=8, eta=4`.

The CLI generates symbolic formulas in `N` and `eta`; it does not take numerical
values for them. The range above applies when substituting integers into the
formulas or interpreting the full table physically. Individual entries may be
valid outside this range, but the complete table is not guaranteed there.
